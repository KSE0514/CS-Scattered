## 컴퓨터가 이해하는 정보
: 데이터, 명령어\
명령어: 수행할 동작과 수행할 대상으로 이루어짐\
데이터: 정적인 정보 ex) 숫자, 문자, 이미지, 동영상\
데이터는 명령어에 종속적인 정보이며, 명령의 대상이자, 명령어의 재료라고 할 수 있음

![alt text](image-1.png)
우리가 작성한 소스 코드는 내부적으로 컴퓨터가 이해할 수 있는 데이터와 명령어의 형태로 전환된 뒤에 실행됨

컴퓨터는 0과 1만으로 다양한 숫자(정수, 실수)와 문자 데이터를 표현하며, 이 데이터를 활용해 명령어를 실행함

명령어를 실행하는 주체: CPU\
> CPU의 종류에 따라 실행 가능한 세부적인 명령어의 종류와 처리의 양상이 달라질 수 있음

![alt text](image-2.png)

## 컴퓨터의 핵심 부품

### CPU
: 데이터와 명령어와 같은 정보를 **읽어 들이고, 해석하고, 실행하는 부품**

구성 요소: ALU(산술논리연산장치), 제어장치(CU), 레지스터(임시 저장장치)\

### 메모리와 캐시 메모리
메인 메모리(일반적으로 RAM을 지칭하는 경우가 많음)는 RAM과 ROM이 있음

메모리: **현재 실행 중인 프로그램**을 구성하는 데이터와 명령어를 저장하는 부품\
프로그램이 실행되려면 그 프로그램을 이루는 데이터와 명령어가 메모리에 저장되어 있어야 함

<주소와 휘발성>
주소: CPU가 메모리에 접근할 때 컴퓨터가 빠르게 작동하기 위해서 정돈되어 저장되는데, 이때 CPU가 원하는 정보로 접근하기 위해 등장한 개념

![alt text](image-6.png)

휘발성: 전원이 공급되지 않을 때 저장하고 있는 정보가 지워지는 특성

> 메모리(RAM)은 휘발성 저장장치=> 메모리에 저장된 정보는 컴퓨터 전원이 꺼지면 모두 삭제됨

캐시 메모리: CPU가 조금이라도 더 빨리 메모리에 저장된 값에 접근하기 위해 사용하는 저장장치\
- CPU와 메모리 사이에는 반드시 하나 이상의 캐시 메모리가 있음
- CPU 안에 위치하기도 하고, CPU 밖에 위치하기도 하며 여러 종류가 있음
![alt text](image-7.png)

### 보조기억장치
: 전원이 꺼져도 저장된 정보가 사라지지 않는 **비휘발성** 저장장치

![alt text](image-8.png)

> 메모리: 실행중인 프로그램을 저장\
> 보조기억장치: 보관할 프로그램을 저장

※ CPU가 보조기억장치에 저장된 프로그램을 곧장 가져와 실행할 수 없음. 실행하려면 보조기억장치에서 보관하고 있는 프로그램을 메모리로 복사해야 함\
![alt text](image-9.png)

### 입출력 장치

![alt text](image-10.png)

<컴퓨터 내부에서 2진수로 소수를 나타내기>
컴퓨터의 소수표현은 표현하고자 하는 소수와 실제로 저장된 소수 간에 오차가 존재할 수 있음(부동 소수점 때문)

부동 소수점: 소수점이 고정되어 있지 않은 소수 표현 방식으로, 필요에 따라 소수점의 위치가 이동할 수 있고 유동적임.
- 컴퓨터 내부에서 소수점을 나타내기 위해 사용하는 대표적인 방식.
- m × 2^n (m: 가수, n: 지수)

![alt text](image-22.png)

오늘날 대부분의 컴퓨터는 2진수의 지수와 가수를 아래와 같은 형식으로 저장(IEEE 754 방식)
![alt text](image-23.png)
> 부호 비트가 0: 양수, 1: 음수

가수의 정수부에는 1로 통일된 **정규화한 수**가 저장됨. 즉 가수는 1.xxx... 형태를 띔

=> ![alt text](image-24.png) 형태의 소수를 저장할 때는 지수에 해당하는 값과 OOO...에 해당하는 소수 부분만 저장하면 됨

이때 컴퓨터가 지수를 저장할 때는 `바이어스`값이 더해져서 저장됨

바이어스 값: 2^(k-1) -1 (k는 지수의 비트 수)\
지수를 표현하기 위해 8비트가 사용되었다면 바이어스 값은 2^7 -1(=127)

- 짧고 규격화된 명령어, 되도록이면 1클럭 내외로 실행되는 명령어를 지향
- CISC보다 많은 명령어가 필요

# Q&A


Q1. 명령어의 구성 요소에 대해 말해보시오.

A1. 명령어는 명령어가 수행할 동작인 연산코드와 동작에 사용될 데이터 혹은 동작에 사용될 데이터가 저장된 위치인 오퍼랜드로 구성되어 있습니다.

Q2. 비동기 인터럽트(하드웨어 인터럽트)가 필요한 이유는 무엇인지 말해보시오.

A2. 비동기 인터럽트는 알림의 역할을 합니다. 입출력장치의 속도가 CPU에 비해 느린데, 만약 비동기 인터럽트를 사용하지 않는다면 CPU는 계속해서 입출력장치의 작업이 완료됐는지 확인해야하고 이로 인해 CPU사용이 낭비될 수 있는 결과를 초래합니다. 따라서 비동기 인터럽트를 이용하면 작업이 끝났음의 여부를 알릴 수 있으므로 CPU 사이클 낭비를 최소화 하고 효율적으로 명령어를 처리할 수 있도록 할 수 있습니다.

Q3. CPU의 성능을 높이는 방법으로는 어떤 것이 있는지 간단히 말해보시오.

A3. CPU의 성능을 높이는 방법은 클럭의 속도를 높이는 방법과 코어 또는 스레드의 수를 늘리는 방법이 있고 또 명령어 파이프라이닝을 통해 명령어를 병렬처리 하는 방식으로 CPU의 성능을 향상시킬 수 있다.
