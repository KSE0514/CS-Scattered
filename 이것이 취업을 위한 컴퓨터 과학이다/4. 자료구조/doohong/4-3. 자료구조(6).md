# 6. 그래프
## 6-1. 그래프의 종류와 구현
 > **그래프** : **정점(vertex)** 이라 불리는 데이터를 **간선(edge)** 혹은 **링크 (link)** 로 연결한 자료구조
- **트리** : 노드와 노드를 간선으로 연결
  - 그래프의 일종 
  - 트리는 사이클을 형성하지 않고 연결된 노드 간에 `상하 관계`를 갖음
- **그래프** : 그보다 `일반적인 연결` 관계를 표현
  - `사이클`을 형성할 수 있음
  - `이웃한 정점끼리 상하 관계를 갖지 않음`
  - 데이터 간 `연결 관계`를 표현하는 자료 구조
    - 예시 : 
        ![Alt text](<images/연결 관계.png>)
- **트리와 그래프 예시**
![Alt text](<images/트리와 그래프.png>)

- **그래프의 구현 방법**
  1. 인접 행렬
       - 이차원 배열을 기반으로 그래프 구현

  2. 인접 리스트
      - 연결 리스트를 기반으로 그래프 구현

<br>  

### (1) 그래프의 유형
1. **연결/비연결 그래프**
    > **연결 그래프** (connected graph) : 그래프 상에 있는 임의의 두 정점 사이의 경로가 존재하는 그래프  

    - 2개의 아무 정점이나 골라 간선으로 서로 이을 수 있는 그래프

    <br>

    > **비연결 그래프** (disconnected graph) : 어떤 정점 사이에는 경로가 존재하지 않을 수 있음

    ![Alt text](<images/연결, 비연결 그래프.png>)

2. **방향/무방향 그래프**
    > **방향 그래프** (directed graph) : 간선에 방향이 있는 그래프

    > **무방향 그래프** (undirected graph) : 간선에 방향이 없는 그래프 

    ![Alt text](<images/방향, 무방향 그래프.png>)

3. **가중치 그래프**
    > **가중치 그래프**(weighted graph) : 간선에 가중치가 부여된 그래프
    
    - **비용** (cost) : 간선에 부여된 가중치 값
      - 양수, `음수` 모두 가능
      - 예시 : 지하철 역과 역 사이를 연결하는 그래프
        - 가중치 : 역과 역 사이의 거리

4. **서브그래프**
    > **서브 그래프** (subgraph, 부분 그래프) : 특정 그래프의 정점과 간선의 일부분으로 이루어진 그래프

    - 예시 : G의 서브 그래프 - H1, H2, H3
      ![Alt text](images/서브그래프.png)

### (2) 그래프 구현 방법 : 인접 행렬 기반 그래프 표현
> **인접 행렬 (adjacency matrix) 기반 그래프 표현** : N*N 크기의 행렬로 그래프를 표현
>
> - **N** : 정점의 개수
> - **N*N 행렬의 (행, 열)** : (출발 정점, 도착 정점)
>   - 연결되었을 경우 1
>   - 연결되지 않았을 경우 0 

- 예시 : 1행 2열 = 1
  - 첫 번째 정점에서 두 번째 정점 방향으로 그래프가 연결되었음

<br>

## 6-2. 깊이 우선 탐색과 너비 우선 탐색
- 모든 정점을 순회하는 탐색 방법
  1. 깊이 우선 탐색
  2. 너비 우선 탐색

### (1) 깊이 우선 탐색
> **깊이 우선 탐색 (DFS, Depth-First Search)** : 그래프에서 더 이상 방문 가능한 정점이 없을 때까지 최대한 깊이 탐색하기를 반복하는 탐색 방법

- 예시 : 사이클이 있는 그래프
  ![Alt text](<images/DFS 예시_그래프.png>)
    - **깊이 우선 탐색 순회 순서** : a -> b -> e -> c -> f -> d
    - **깊이 우선 탐색 알고리즘 구현을 위한 자료구조** : 배열과 스택
      - **배열** : 특정 정점의 `방문 여부` 확인
      - **스택** : 방문 중 `뒤로가기`가 필요할 경우 사용
        - 내가 재귀로 DFS를 할 때 놓친 부분
        - DFS는 과거 노드에서 미방문한 연결 노드가 있는지 다시 확인하기 위해 뒤로가기를 함

## Q&A
### Q1. 그래프를 인접 행렬과 인접 리스트로 구현하는 방법에 대해 설명해보세요.

A1. 
- 긴 답변 
  - 그래프를 구현하는 방법에는 **인접 행렬**과 **인접 리스트**가 있습니다.  
  **인접 행렬**은 정점 수가 N개일 때 N×N 크기의 이차원 배열을 사용하여, 연결 여부를 1과 0으로 표시합니다. 연결 여부 확인은 빠르지만, 공간 복잡도가 O(N²)로 큽니다.  
  **인접 리스트**는 각 정점마다 연결된 정점들을 리스트로 관리합니다. 공간 복잡도는 O(N+E)로 효율적이며, 연결 여부를 확인할 때는 리스트를 순회해야 하므로 약간 느릴 수 있습니다.

- 초간단 버전  
  - 인접 행렬은 공간을 많이 쓰지만 연결 여부 확인이 빠르고, 인접 리스트는 공간을 아끼지만 연결 여부 확인이 느릴 수 있습니다.

---

### Q2. 깊이 우선 탐색(DFS)과 너비 우선 탐색(BFS)의 차이점을 설명해보세요.

- 긴 답변  
  - **DFS(깊이 우선 탐색)** 은 가능한 한 깊게 탐색한 후, 막히면 뒤로 돌아가는 방식입니다. 스택이나 재귀를 사용합니다.  
  **BFS(너비 우선 탐색)** 은 가까운 정점들을 먼저 모두 방문한 뒤, 그 다음 가까운 정점들을 방문하는 방식입니다. 큐를 사용합니다.  
  DFS는 경로 탐색이나 사이클 검사에, BFS는 최단 경로 탐색에 주로 활용됩니다.

- 초간단 버전  
  - DFS는 깊게, BFS는 넓게 탐색하며, 각각 스택/큐를 사용합니다.

### Q3. 다익스트라 알고리즘은 어떤 상황에서 사용할 수 있으며, 주의할 점은 무엇인가요?

- 긴 답변  
  - **다익스트라 알고리즘**은 가중치가 0 또는 양수일 때 사용 가능한 최단 경로 알고리즘입니다.  
  한 정점에서 다른 모든 정점까지의 최단 거리를 구할 수 있으며, 음수 가중치가 있으면 사용할 수 없습니다.  
  구현 시에는 우선순위 큐(힙)를 사용하여 효율적으로 최단 거리를 갱신합니다.

- 초간단 버전  
  - 다익스트라는 가중치가 양수일 때만 사용하고, 우선순위 큐를 쓰면 빠릅니다.
