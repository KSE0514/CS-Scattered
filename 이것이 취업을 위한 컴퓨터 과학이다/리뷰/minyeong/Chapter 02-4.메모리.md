## RAM
- Random Access Memory(임의의 접근 메모리)
  - 임의의 위치에 곧장 접근 가능 → 어떤 데이터든 접근 시간 동일
  - ↔ 순차 접근(특정 위치에 저장된 요소에 접근하기 위해 처음부터 접근)
- 휘발성 저장장치 : 전원을 끄면 저장하고 있던 데이터와 명령어 날라감
  - RAM이 크면 보조기억장치로부터 많은 데이터를 가져와 미리 저장 → 많은 프로그램 동시 실행 유리(컴퓨터 성능과 반드시 비례하진 않음)
- 종류
  - DRAM(Dynamic RAM)
    - 시간이 지나면 **저장된 데이터가 점차 사라지는** RAM
    - 데이터 소멸 막기 위해 일정 주기로 데이터 재활성화
    - 소비 전력 낮음, 저렴, 집적도 높음 ⇒ 메모리 대용량 설계 용이 ⇒ 일반적으로 사용
  - SRAM(Static RAM)
    - 시간이 지나도 **저장된 데이터가 사라지지 않는** RAM
    - 전원이 공급되지 않으면 저장된 내용 소실됨 ⇒ 비휘발성은 아님
    - DRAM에 비해 속도는 빠르나 소비 전력 크고, 비싸고, 집적도 낮음 ⇒ **캐시 메모리** 등 (대용량으로 만들 필요 없고 속도가 빨라야 하는 저장장치)
  - SDRAM(Synchronous Dynamic RAM)
    - 클럭 신호와 동기화된 DRAM
    - 클럭 타이밍에 맞춰(한 클럭당 한 번씩) CPU와 정보 주고 받을 수 있음 (= SDR SDRAM)
  - DDR SDRAM(Double Data Rate SDRAM)
    - 두 배로 대역폭을 넓혀 속도를 빠르게 만든 SDRAM
    - 대역폭 : 데이터를 주고받을 길의 너비
    - SDRAM보다 전송 속도 두 배 가량 빠름

## 빅 엔디안, 리틀 엔디안
- CPU로부터 워드 단위(4바이트, 8바이트)로 받아들인 데이터를 바이트 단위로 여러 메모리 주소에 저장
- 빅 엔디안 : 낮은 번지의 주소에 가장 큰 값(상위 바이트)부터 저장
  - 메모리 값을 직접 읽거나 디버깅
- 리틀 엔디안 : 낮은 번지의 주소에 가장 작은 값(하위 바이트)부터 저장
  - 수치 계산 편리
 
## 캐시 메모리
- CPU와 메모리 사이에 위치한 SRAM 기반의 저장장치
  - CPU의 연산 속도와 메모리 접근 속도의 차이를 줄이기 위한 저장장치
  - CPU가 **메모리**에 접근 하는 속도 < CPU가 **레지스터**에 접근하는 속도
  - **CPU가 사용할 것으로 예측되는** 일부 데이터를 미리 캐시 메모리로 가져와 활용
- 종류
  - L1, L2, L3
  - 코어 내부(L1, L2), 코어 외부(L3)
    - 멀티코어 프로세서 - 코어마다 고유한 캐시 메모리로 할당(L1, L2), 여러 코어가 공유(L3)
    - 분리형 캐시 - 명령어만 저장(L1I 캐시), 데이터만 저장(L1D 캐시)
  - 크기 : L1 < L2 < L3
  - 속도 : L3 < L2 < L1
- 캐시 히트와 캐시 미스
  - 캐시 히트 : 예측된 데이터가 CPU에 의해 실제로 사용되는 경우
  - 캐시 미스 : 틀린 예측으로 인해 CPU가 메모리로부터 필요한 데이터를 직접 가져와야 하는 경우
  - 캐시 적중률 : 캐시가 히트되는 비율
- 참조 지역성의 원리
  - 시간 지역성 : CPU는 **최근에** 접근했던 메모리 공간에 다시 접근하려는 경향이 있음 (예 - 변수)
  - 공간 지역성 : CPU는 **접근한 메모리 공간의 근처**에 접근하려는 경향이 있음 (예 - 배열)
- 캐시 메모리의 쓰기 정책과 일관성
  - 즉시 쓰기 : 캐시 메모리와 메모리 동시에 쓰는 방법(일관성 O)
    - 메모리를 항상 최신 상태로 유지
    - 데이터 쓸 때마다 메모리 참조
    - 버스의 사용 시간과 쓰기 시간 늘어남
  - 지연 쓰기 : 캐시 메모리에만 값을 써두었다가 수정된 데이터를 한 번에 메모리에 반영하는 방법(일관성 △)
    - 메모리 접근 횟수 줄여 속도 빠름
