# 질문

### Q: 프로세스와 스레드의 차이점을 설명해주세요.

프로세스는 실행 중인 프로그램으로, 독립된 메모리 공간을 할당받습니다. 반면 스레드는 프로세스 내의 실행 흐름 단위로, 프로세스의 메모리 공간을 공유합니다. 프로세스는 자원을 많이 사용하고 문맥 교환 비용이 크지만, 스레드는 자원을 공유하므로 더 효율적입니다.

### Q: 캐시 메모리가 필요한 이유와 작동 원리를 설명해주세요.

캐시 메모리는 CPU의 연산 속도와 메모리 접근 속도의 차이를 줄이기 위한 저장 장치입니다. 참조 지역성의 원리를 활용하여 CPU가 가까운 미래에 사용할 것 같은 데이터를 미리 저장해둡니다. 이를 통해 메모리 접근 시간을 줄이고 전체적인 시스템 성능을 향상시킵니다.

### Q: 교착 상태(데드락)란 무엇이며, 발생 조건과 해결 방법을 설명해주세요.

교착 상태는 프로세스들이 서로가 가진 자원을 기다리며 무한히 대기하는 상태입니다.
발생 조건에는

- 상호 배제: 자원은 한 번에 한 프로세스만 사용 가능
- 점유와 대기: 자원을 가진 상태에서 다른 자원을 요청
- 비선점: 다른 프로세스의 자원을 강제로 빼앗을 수 없음
- 원형 대기: 프로세스의 자원 요청이 순환 형태를 이룸

해결 방법은

- 예방: 발생 조건 중 하나를 제거
- 회피: 안전 상태를 유지하는 범위에서만 자원 할당
- 검출 및 회복: 교착 상태 발생 시 검출하고 회복

### Q: 가상 메모리의 페이징 시스템에 대해 설명해주세요.

페이징은 물리 메모리를 프레임 단위로, 프로세스의 논리 주소 공간을 페이지 단위로 나누어 관리하는 기법입니다. 페이지 테이블을 통해 각 페이지가 어느 프레임에 있는지 매핑하며, 필요한 페이지만 메모리에 적재하는 요구 페이징 방식을 사용합니다. TLB를 통해 페이지 테이블 접근 속도를 개선합니다.

### Q: CPU 스케줄링의 주요 알고리즘들을 비교해서 설명해주세요.

- FCFS(선입 선처리): 먼저 온 프로세스를 먼저 처리. 단순하지만 긴 프로세스가 앞에 있으면 효율성 떨어짐
- SJF(최단 작업 우선): CPU 사용 시간이 가장 짧은 프로세스 먼저 실행. 효율적이나 기아 현상 발생 가능
- Round Robin: 각 프로세스에 동일한 시간량을 할당하여 순환. 응답 시간 좋으나 문맥 교환 오버헤드 큼
- 우선순위: 우선순위가 높은 프로세스부터 실행. 중요 작업 먼저 처리 가능하나 기아 현상 발생 가능
