Q1. 레지스터의 종류 중 하나인 범용 레지스터를 메모리 주소 레지스터와 메모리 버퍼 레지스터와 비교하며 설명 하시오.

A1. 메모리 버퍼 레지스터 데이터 버스로 주고받을 값만 저장하고 메모리 주소 레지스터는 주소 버스로 내보낼 값만 저장하는 레지스터인 반면 범용 레지스터는 데이터와 주소를 모두 저장할 수 있는 레지스터입니다.

Q2. 인터럽트가 무엇인지 동기 인터럽트와 비동기 인터럽트로 나눠 간단히 설명하시오.

A2. 인터럽트는 CPU의 작업을 방해하는 신호로 크게 동기 인터럽트와 비동기 인터럽트로 나눠볼 수 있습니다. 동기 인터럽트는 CPU가 예외적인 상황에 마주했을 때 발생하는 인터럽트이고, 비동기 인터럽트는 알림과 같은 인터럽트이며 주로 입출력장치에 의해 발생하는 인터럽트입니다.

Q3. 인터럽트 백터와 인터럽트 서비스 루틴에 대해 설명하시오.

A3. 인터럽트 서비스 루틴은 어떤 인터럽트가 발생했을 때 해당 인터럽트를 어떻게 처리하고 작동해야 할지에 대한 정보로 이루어진 프로그램이며, 이러한 인터럽트 서비스 루틴을 식별하기 위한 정보를 인터럽트 벡터라고 합니다.

Q4. 프로세스 상태의 종류와 각 상태의 흐름에 대해 간단히 설명하시오.

A4. 프로세스 상태 종류로는 생성 상태, 준비 상태, 실행 상태, 대기 상태, 종료 상태가 있습니다. 생성 상태는 프로세스를 생성 중인 상태를 뜻하며, 이 단계를 거쳐 실행할 준비가 완료 되면 준비 상태로 바뀌는데 준비 상태는 당장이라도 CPU를 할당받아 실행 될 수는 있지만 자신의 차례가 아니기 때문에 기다리고 있는 상태입니다. 준비 상태였던 프로세스의 차례가 되면 CPU를 할당 받아 실행 상태로 바뀌며, 이 상태 이후엔 상황에 따라 준비 상태로 되돌아가거나 대기 상태가 되거나 종료 상태로 바뀝니다. CPU 사용 가능 시간 종료를 알리는 타이머 인터럽트가 발생할 경우엔 준비 상태로 바뀌어 다시 본인의 차례가 되길 기다리고, 입출력 요청이 필요한 경우엔 대기 상태로 바뀌었다가 입출력 작업이 완료되면 다시 준비상태로 돌아갑니다. 만약 실행 상태에서 프로세스의 실행이 완료되면 종료상태가 됩니다.

Q5. 교착 상태에 대해 설명하시오.

A5. 두 개 이상의 프로세스가 각자 가지고 있는 자원을 무한정 기다리며 어떤 프로세스도 더 이상 진행할 수 없는 상태를 교착 상태라 합니다.
